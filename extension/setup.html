Add to a browser

Use this page if you closed the setup window, or to load PasteFlick in another Chromium browser. Same extension for Brave, Chrome, Edge, Chromium, and Arc.

2. Load unpacked

  1. Open your browser extensions page (paste one of these into the address bar):
  • Brave — brave://extensions/
  • Chrome — chrome://extensions/
  • Edge — edge://extensions/
  • Chromium / Arc — chrome://extensions/
  1. Turn on Developer mode (top-right).
  2. Click Load unpacked.
  3. Paste the path from step 1 and open that folder.

Browsers block fully silent installs. Load unpacked is the last step. Repeat it in each browser you use. Then refresh the chat tab.

3. How to use

The first time you copy, ChatGPT or the browser may ask if it can use the clipboard. Allow it — click Copy or Allow on that chip. If you skip it, PasteFlick has nowhere to put the text.

On the chat

  • Each message has a Message card on its left, with Copy, Auto-paste, and Save. ChatGPT’s own buttons stay on the right.
  • Code, tables, files, and documents each get a smaller card with the same three actions. On code, Auto-paste is the main one — ChatGPT already copies code.
  • The bookmark on a Message card is where Copy from PasteFlick starts.

From the PasteFlick popup

  • Copy selection — highlight part of the thread, then copy.
  • Copy thread — the whole conversation.
  • Copy from PasteFlick — from the bookmark onward.

Copies stay on the clipboard unless you turn on Auto-paste or File in Settings. Save on a card uses the format you pick there (Markdown or PDF). After an update, reload the extension on the Extensions page, then refresh the chat.
